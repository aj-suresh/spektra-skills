# Report Template

Save as `<draft name> – internal links.md` next to the linked copy. Leave out empty sections, except "Flags", which always appears (write "None" when there are none).

```markdown
# Internal links: {draft title}

**Draft:** {original file} → **Linked copy:** {linked file}
**Home site:** {domain} · **Also searched:** {other domains or "none"}
**Primary keyword:** {keyword} ({given by writer | inferred from title/H2s})
**Planned URL:** {url | {new-post-url}}
**Search Console:** {used for N pages | unavailable: reason}
**Assumptions:** {anything you defaulted because the writer said "go"}

## Flags
- {Cannibalization: page X ranks #N for "keyword" (N impressions/90d). Recommendation: …}
- {Must-link page couldn't be placed naturally: …}
- {None}

## Outbound links inserted ({n} · ~1 per {words/n} words)

| # | Where | Anchor | Target | Type | Why |
|---|---|---|---|---|---|
| 1 | P7 · Month 2 | "LTI grade pass-back into Canvas or Moodle" | /platform/lms-integration | money | Faculty requirement → the integration page; page ranks #8 for "lti grade passback" |
| 2 | … | … | … | blog / SISTER / … | … |

## Optional links (need writer approval)
| Where | Suggested wording | Target | Why it's not inserted |
|---|---|---|---|

## Inbound links to add on existing pages ({n})

| # | Source page | Existing sentence (exact) | Anchor | Notes |
|---|---|---|---|---|
| 1 | /glossary/proof-of-concept | "A POC is the structured way to deliver that evidence." | "structured way to deliver that evidence" → {new-post-url} | 1.2k impressions/90d for "poc" queries |
| 2 | /blog/… | **New sentence:** "For a step-by-step plan, see our POC playbook for ISVs." | "POC playbook for ISVs" | No existing sentence fits |

## Considered and rejected
- {url}: {reason, e.g. same concept as the hub page / dated 2023 / thin page / writer asked to avoid}

## Content gaps
- {Concept the draft mentions where no page exists to link to, e.g. "no page explains per-student cost caps"}
```

Keep "Why" to one line. The writer reads it to trust the link, so it doesn't need to justify itself in an essay.
